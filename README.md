# The Human Code

A free, experimental Head–Heart–Hands personality discovery website from Strategic Intelligence Lab.

## Current release
- v0.2: 12 situational questions
- Three domains: Head, Heart, Hands
- Nine provisional orientations
- Transparent client-side counts, including ties
- Personal reflection report with no required account or database

## Running locally
Open `index.html` in a browser. There are no build dependencies.

## Deployment
The live Vercel project is `the-human-code` (project ID `prj_AmDgVH3qeaskFcVuKjx1xPTvCPjJ`). Historically it was deployed by direct Vercel API uploads. Connect **this repository** to that existing project in Vercel's Git settings before assuming automatic deployments are active. Do not create a duplicate Vercel project.

## Product theory
Head (Sage / Explorer / Architect): how someone approaches understanding.
Heart (Caregiver / Weaver / Idealist): what someone values.
Hands (Builder / Guardian / Catalyst): characteristic approaches to action.

These archetypes are narrative hypotheses, **not validated psychological categories**. Scores count four selections per domain, not population percentiles or clinical traits.
